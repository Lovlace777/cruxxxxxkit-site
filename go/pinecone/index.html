Pros / 核心优势

  • Serverless architecture scales to zero when idle and handles millones of vectors without shard management
  • Built-in hybrid search combines dense semantic embeddings with sparse BM25 keyword matching
  • Native integrations with LangChain, LlamaIndex, Make.com, and n8n
  • Serverless 架构闲置时几乎零成本，自动弹性扩容无需管理分片
  • 原生支持语义向量（Dense）与精确关键词（Sparse BM25）混合检索，专治产品型号漏检
  • 与 Make.com、n8n、LangChain 与 Dify 原生无缝集成

Trade-Offs / 局限与注意事项

  • If you already run Supabase Postgres with under 50k rows, `pgvector` may be enough
  • 若数据量较小（<5万条）且已在用 Supabase，也可直接使用 pgvector
